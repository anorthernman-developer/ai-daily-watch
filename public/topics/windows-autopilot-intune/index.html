  2. Microsoft

    Microsoft outlines trust-list changes after eMudhra certificate key compromise

    Microsoft described its response to compromised eMudhra certificate authority keys, including an October 26 out-of-band Windows update removing seven related certificates from the Windows trust list. Microsoft also said it planned to remove those certificates from the Edge trust list on October 27 and advised administrators to check disconnected devices.
