    GitHub REST API adds a cost-center lookup for resources

    GitHub added a REST API endpoint to look up the cost center associated with a user, organization, repository, or enterprise team. The response returns the cost-center ID and name, simplifying billing and cost-center workflows that previously required scanning cost-center resource lists; access depends on the caller’s role.

  8. Anthropic

    Anthropic opens Messages API message threads beta to speed up long-running agents

    Anthropic launched message threads in public beta for the Messages API: after the initial conversation, developers can send only new messages rather than resending the full history. Anthropic says requests of 500,000 to 1 million tokens see about 35% lower median time to first token; the beta is available on Claude Platform, AWS, Microsoft Foundry, and Anthropic-managed Claude on Google Cloud.

    feature update · Published 2 Nov 2026 · Briefing 4 Nov 2026 · claude.com

  9. Anthropic

    Anthropic releases FlashProve, an open-source prototype for provable inference

    Anthropic published research on FlashProve, an open-source prototype for cryptographically verifying model inference while keeping model weights hidden. It released code, Lean formalization, and protocol documentation; the work advances inference verification research, though Anthropic identifies it as an intermediate prototype with technical limitations.

    research · Published 2 Nov 2026 · Briefing 4 Nov 2026 · anthropic.com

  10. OpenAI

    OpenAI introduces LifeVal, a benchmark for AI assistance with everyday tasks

    OpenAI introduced LifeVal, a benchmark intended to measure AI performance on practical everyday tasks, extending evaluation beyond conventional question-answering. Its task selection draws on U.S. and international time-use datasets and a demographically representative survey of 3,995 respondents.

    research · Published 2 Nov 2026 · Briefing 4 Nov 2026 · openai.com

    OpenAI said it is planning an internal security sprint with Cathedral Systems, whose researchers will work alongside OpenAI teams using OpenAI models to test and strengthen the company’s systems. The announcement describes the effort as a way to challenge defenses and help protect its platforms.
