    Salesforce adds agent evaluations and cost controls to Agent Fabric

    Salesforce expanded Agent Fabric with Agent Evals and API Evals to test agent quality and API changes, plus cost controls that can impose hard budget limits and reduce token usage. The additions are aimed at catching silent failures and overspending as organizations put more agents into production; Agent Evals and API Evals are scheduled for beta in November 2026 and general availability in January 2027.

    Google DeepMind expands Gemini-powered PlanAssist to 12 more councils

    Google DeepMind is expanding its Gemini-powered PlanAssist tool to 12 additional local planning authorities in England, bringing the total involved to 15 for a 12-month beta using live applications. Early pilots reported a 58% reduction in time spent on householder application assessments, while qualified planning officers retain final approval.

    feature update · Published 31 Oct 2026 · Briefing 2 Nov 2026 · deepmind.google

The demonstration is a notable example of Gemini-powered agents being used in a real-world robotics workflow without manual CAD.

  8. AI trendsGoogle DeepMind; World Resources Institute

    Google DeepMind and WRI create AI-based global forest map

    Google DeepMind and the World Resources Institute developed ForTy, a global map that classifies 2020 land cover into six categories at 10-meter resolution using satellite data and AI. The reported overall accuracy was 90.2%, though the article notes weaker identification of some tree crops and plantations, relevant limitations for land-use monitoring.
